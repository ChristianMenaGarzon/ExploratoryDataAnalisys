# Exploratory Data Analysis

Repositorio correspondiente al laboratorio de Procesamiento de Datos a Gran Escala.

## Descripción

En este laboratorio se desarrollaron ejercicios prácticos utilizando Python para estudiar diferentes estructuras, operaciones y conceptos fundamentales del lenguaje, aplicados al procesamiento y análisis de datos.

## Lab 01 - Python

El laboratorio está compuesto por los siguientes notebooks:

### 01 - Python Cadenas
Operaciones con cadenas de texto, indexación, indexación negativa, slicing y secuencias de escape.

### 02 - Python Tuplas
Creación, acceso y operaciones con tuplas.

### 03 - Python Listas
Creación, modificación, acceso y operaciones con listas.

### 04 - Python Conjuntos
Creación y operaciones con conjuntos.

### 05 - Python Diccionarios
Creación, acceso, modificación y uso de métodos de diccionarios.

### 06 - Python Condiciones
Uso de estructuras condicionales para controlar el flujo de los programas.

### 07 - Python Bucles
Uso de ciclos `for` y `while` para repetir instrucciones y recorrer estructuras de datos.

### 08 - Python Funciones
Creación, utilización y comprensión de funciones en Python.

### 09 - Python Clases
Introducción a la programación orientada a objetos mediante la creación de clases, atributos, métodos y objetos.

## Práctico Bono

Se desarrolló adicionalmente el notebook `Practico_Bono_1.ipynb`, compuesto por ejercicios de funciones organizados en diferentes niveles de dificultad.

Los ejercicios incluyen:

- Menor de dos pares
- Galletas de animales
- Hace veinte
- Mayúsculas
